# Kulit Barkada v1.3.0

App icon, wireframe Equal/Custom split flow, and budget removed.

## Download

Install **[BarkadaPlan-v1.3.0.apk](https://github.com/betroyer/KulitBarkada/releases/download/v1.3.0/BarkadaPlan-v1.3.0.apk)** on Android.

1. Uninstall the older Kulit Barkada app first (so the new icon shows)
2. Download and open the APK
3. Allow install from this source if asked

## What's new

- Home-screen icon uses the 3D zany emoji
- Group hub leads with EQUAL / CUSTOM split
- Equal Split: enter total → auto-shares → TOTAL
- Custom Split: add amounts → TAP spin → member totals
- Budget field removed from create group, dashboard, summary, and plan

Still fully offline. Data stays on the device.
